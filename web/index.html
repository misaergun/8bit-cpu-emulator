    Assembly syntax
    • label: names an address; use it in JMP, JZ, JE, JL, JG, CALL, LOAD_MEM, STORE, STORE_B.
    • ; text is a comment. Mnemonics and labels are not case-sensitive.
    • Numbers 0–255: 42, 0x2A or 0b101010. .byte 1, 2, 3 stores raw data.
    • Value operand: LOAD, LOAD_B, ADD, SUB. Address operand: the jumps, CALL, LOAD_MEM, STORE, STORE_B. No operand: MOV_A_B (A←B), MOV_B_A (B←A), ADD_B, SUB_B, CMP, AND, OR, XOR, NOT, SHL, SHR, PUSH, POP, RET, HALT.
    • JZ jumps when A is 0. JE/JL/JG use the flags set by CMP.
    • Code and data use addresses 0x00–0xBF (192 bytes). 0xC0–0xFF is the stack.
